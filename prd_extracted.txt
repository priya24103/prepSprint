FINAL WEB PRODUCT REQUIREMENTS DOCUMENT + TECHNICAL BUILD SPECIFICATION
Revise Smart. Be Placement Ready. | Version 3.0 | Responsive mobile-first web application | 5-day MVP
0. Critical Build Directive for Antigravity
Build PrepSprint as a complete, deployable, mobile-first web application. The primary use case is a student revising on a phone immediately before a placement test/interview, while the same application must work well on laptop/desktop.
Use Java 17+, Spring Boot, Spring Data JPA, MySQL, Maven, Thymeleaf, HTML5, CSS3 and vanilla JavaScript. Use REST endpoints where useful for asynchronous interactions, but do not introduce React or another frontend framework for the 5-day MVP.
The application must be a real full-stack Java project: Java/Spring Boot contains business logic and persistence integration; Thymeleaf/HTML/CSS/JS provide the responsive interface. Build P0 first, then P1, then polish and deployment.
1. Product Vision
PrepSprint is a last-minute placement revision companion. It centralizes Core CS concepts, DSA, aptitude formulas, logical/verbal practice, MCQs, flashcards, technical interview questions and HR interview preparation. Its differentiator is guided revision: performance identifies weak areas, and the system turns that information into short Sprint sessions and Placement Day sessions.
Core loop: Learn -> Practice -> Measure -> Identify Weakness -> Recommend -> Revise.
2. Goals
Make placement revision accessible anywhere from a phone browser.
Provide fast, scannable content instead of long notes.
Generate useful 15/30/60-minute revision sessions.
Track performance, weaknesses, bookmarks, activity and streak.
Provide Core Java/Spring Boot/SQL concepts that can be explained in a viva.
Deliver a polished responsive interface suitable for both phone and desktop.

16. Recommendation Engine
Use a deterministic weighted score: weaknessScore + unattemptedScore + bookmarkScore + adminPriorityScore + difficultyScore + recencyScore.
Signal
Behavior
Weakness
Lower topic accuracy -> higher score.
Unattempted
Never attempted/reviewed -> strong boost.
Bookmark
Bookmarked -> strong boost.
Priority
Admin priority 1-5 -> modest boost.
Difficulty
Medium/hard -> modest boost.
Recency
Long time since review -> boost.
Duplicates
Exclude items already in current session.
Keep weights in RecommendationConfig. Dashboard recommendation should explain why: e.g. 'SQL Joins is weak at 42% accuracy.'
17. Progress / Scoring
MCQ percentage = correct / total * 100. Topic classification: fewer than 3 attempts = Not Enough Data; below 60% = Weak; 60-79% = Needs Practice; 80%+ = Strong.
Recommended overall score: 60% content coverage + 40% quiz accuracy. Define this in ProgressService and use it consistently.
Content coverage should be based on the proportion of active content meaningfully reviewed/attempted by the user, capped at 100%.

33. Final Product Definition
PrepSprint is a mobile-first, full-stack Java web application for rapid placement revision. Its defining experience is not merely storing questions: it measures what the student knows, identifies weak areas, and immediately creates a focused revision path. A student should be able to open the site on a phone, choose 15/30/60 minutes, revise the highest-value material, and leave with a clear understanding of what to practice next.
